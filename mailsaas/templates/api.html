Quick start

Verify an address from the command line:

curl "{{ request.host_url }}api/v1/verify?email=test@gmail.com" \ -H "Authorization: Bearer YOUR_API_KEY"

Response:

{ "email": "test@gmail.com", "result": "valid", "score": 100, "reason": "Deliverable", "checks": { "syntax": true, "mx": true, ... } }
